Simple learning project creating a 2D Minecraft clone implemented using python/pygame.

All textures belong to the creators of Minecraft.

Page last updated 10/30/2026.

## Current Features:
- Chunking
- Procedural world generation
- Caves
- Inventory system
- Physics
- Breaking and placing blocks
- Entities
- Random ticking (At the moment, only used for grass spreading)

## Future Features to implement! (From smaller tasks to larger ones)
- Crouching and sprinting (and animations)
- Dropping items
- Blocks dropping themselves as an item when broken
- Item functions, beside BlockItem
- Block durability 
- Player health and hunger
- Inventory management
- Crafting…

## Controls
| Control                       | Action |
|-------------------------------|----------------------------------------------------------------|
| Left mouse                    | Break block |
| Right mouse                   | Place block |
| Arrow keys or WASD            | Move/Jump |
| Space | Jump                  |
| Left shift                    | Crouch (crouching animation still needs to be implemented) |
| 0-9                           | Select item in hotbar |
| e                             | Open/close inventory |
